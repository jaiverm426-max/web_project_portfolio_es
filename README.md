# Portafolio personal — Jaiver Martinez

## Descripción del proyecto

Este proyecto es mi portafolio personal como desarrollador web Full-Stack Junior. Lo creé con el propósito de presentar mi perfil profesional, compartir las tecnologías con las que trabajo y mostrar los proyectos que he desarrollado durante mi proceso de aprendizaje.

El sitio reúne una breve presentación personal, una sección de habilidades y herramientas, una selección de proyectos y un apartado de contacto. Mi objetivo es contar con un espacio profesional en el que pueda mostrar mi trabajo, seguir incorporando nuevos proyectos y compartir mi evolución como desarrollador.

## Tecnologías utilizadas

- **HTML5:** para estructurar el contenido de la página mediante etiquetas semánticas.
- **CSS3:** para definir los estilos visuales, los colores, la tipografía y la distribución de los elementos.
- **Flexbox:** para organizar y alinear los componentes de la interfaz.
- **CSS Grid:** para distribuir las habilidades y las tarjetas de proyectos.
- **Media queries:** para adaptar el diseño a diferentes tamaños de pantalla.
- **BEM:** para organizar los nombres de las clases CSS y mantener un código claro y fácil de mantener.
- **Open Sans y Archivo Black:** fuentes tipográficas utilizadas para mantener la identidad visual del diseño.
- **Git y GitHub:** para gestionar y publicar el proyecto.
- **GitHub Pages:** para desplegar el sitio web.

## Características principales

- Presentación personal y perfil profesional.
- Sección de habilidades y herramientas de desarrollo.
- Tarjetas para presentar proyectos, con imágenes, tecnologías y enlaces.
- Diseño adaptable a escritorio, tabletas y dispositivos móviles.
- Efectos visuales al pasar el cursor sobre determinados elementos.
- Degradados y efectos de iluminación creados con CSS.
- Enlaces al currículum, GitHub y medios de contacto.

## Proyecto destacado

### Página web de una cafetería — Triple Espresso

Uno de los proyectos que presento es una página web para una cafetería, desarrollada como parte de mi formación. Durante su construcción trabajé con HTML y CSS, estructura semántica, Flexbox y organización del código.

El proyecto me permitió practicar la interpretación de un diseño de referencia, la implementación de sus componentes y la publicación de una página web utilizando GitHub Pages.

## Diseño adaptable

El portafolio está diseñado para adaptarse a diferentes resoluciones de pantalla, tomando como referencia los tamaños de escritorio, tableta y móvil establecidos en el diseño de Figma.

Para lograrlo, utilizo Flexbox, CSS Grid, imágenes adaptables y consultas de medios que permiten reorganizar los elementos según el espacio disponible.

## Organización del proyecto

El proyecto está organizado en archivos y carpetas para facilitar su mantenimiento:

- `index.html`: estructura principal del sitio.
- `styles/`: hojas de estilo CSS.
- `images/`: fotografías, iconos e imágenes de los proyectos.
- `fonts/`: archivos de las fuentes tipográficas locales.
- `favicon.ico`: icono del sitio web.
- `descargas/`: hoja de vida.

Continuaré actualizando este portafolio a medida que desarrolle nuevos proyectos y adquiera experiencia.
